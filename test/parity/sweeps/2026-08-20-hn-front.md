# Conformance sweep: the Hacker News front page, 2026-08-20

Every article linked from the front page, captured through the real pipeline
and triaged with `skyhookctl bundle triage` — the bundle tooling's first
contact with thirty pages nobody wrote to be measurable. Run with
`scripts/bundle_sweep.py`; the landside browser's egress was
proxy-filtered in the environment this ran in, so each article was fetched
with curl and served to the pipeline from a local mirror, scripts stripped
(the corpus rule: a page that mutates under measurement measures the
weather).

**The bundles themselves are not committed** — they contain the articles.
This file records what the sweep found; the sweep is reproducible against
any URL list.

## Result

25 of 30 articles fetched (github.com ×3, casio.com and openai.com answered
403 to the fetch). After the tool fixes below: **23 of 25 bundles triage
clean; the 2 diverged are both P-127**, the injection race, correctly
detected — one bundle holds a three-node about:blank wire against a fully
rendered page (`agent.json` says `started:false`), the other an agent
answering `serverHash 2166136261`, the bare FNV basis, for a 2068-node
document it had already delivered.

## What it taught the triage tool

Each of these read as divergence until the tool learned the machinery
behind it (all now pinned by unit tests in `internal/parity/triage_test.go`):

- React SSR's `<!-- -->` separators shard text runs that the wire re-joins
  (theverge.com, fx.sh) — adjacent text nodes now merge before comparison.
- The agent stamps `data-sky-undefined` on not-yet-defined custom elements
  (MathJax, Wix, devblogs' `uhf-*`, one blog's inline demo element) — every
  `data-sky-*` synthetic is now skipped by prefix.
- A frame's children and attributes are two machines' furniture: fallback
  markup landside, the stand-in's label text and `data-sky-box` on the wire
  (YouTube embeds) — frames now compare as opaque leaves.
- The fingerprint writers disagree at the edges — nodeType against protocol
  kind, `clippath` against `clipPath`, 32 UTF-16 units against 32 runes
  (P-128) — the cross-diff now compares with the hash's own semantics.
- An empty fingerprint against a populated one is an unstarted agent
  (P-127), not thousands of missing nodes.

## Gaps filed from this sweep

- **P-127** — the isolated-world injection race can leave a tab unmirrored;
  seven `isolated world setup failed` warnings in one hour of captures,
  two of which never recovered.
- **P-128** — the three fingerprint writers disagree at the edges, so the
  hand-diff `docs/OPERATIONS.md` describes reports phantom rows on any page
  with SVG, sub-frames or emoji.

(The same day's corpus imports had already filed P-124, the cross-language
hash divergence on non-ASCII text; P-125, quirks mode; and P-126, var()
shorthand longhands — see `gaps.json`.)

## Reproducing

```sh
# a running skyhookd and its pairing file, then:
scripts/bundle_sweep.py -urls stories.txt -out /tmp/sweep \
    -pairing ~/.skyhook/pairing.json
```

The URL list was the thirty `titleline` links of the front page as of
2026-08-20 07:30 UTC.
